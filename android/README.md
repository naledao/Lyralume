# Lyralume Android

Lyralume Android 是桌面端 MinIO 音乐库的只读移动客户端。应用只读取 `lyralume/v1/tracks/` 前缀中的对象，可以把原始音频下载到用户授权的 Android 目录；不会上传、覆盖或删除远程对象。

## 当前功能

- 底部固定“本地音乐”和“远程音乐”两个入口。
- 两个主页面分别保存列表滚动位置及 `rememberSaveable` 页面状态；切换 Tab、打开设置或进入正在播放页再返回时不会重建为初始位置。切换 Tab 本身不触发本地扫描或远程刷新，数据只在用户点击“刷新”或下载、删除完成时更新。
- 设置 MinIO API、Bucket、用户名（Access Key）和密码（Secret Key）。
- 使用 Android Keystore 的 AES-GCM 密钥加密保存 MinIO 密码。
- 通过系统 `ACTION_OPEN_DOCUMENT_TREE` 选择下载目录并持久保留读写授权。
- 读取桌面端写入的歌曲名、艺术家、专辑、时长、文件名和 SHA-256 元数据。
- 远程列表会先显示本机持久缓存，再在后台刷新；每次只重新读取新增或已变化对象的元数据，首次读取最多并发 6 个请求。
- 显示远程音乐并下载原文件，实时显示进度，下载后校验 SHA-256。
- 远程列表提供“一键下载未下载”，由 WorkManager 在后台按列表顺序逐首下载；通知栏显示总进度并可停止任务。
- 后台任务会在应用离开前台后继续运行；进程被系统回收或设备重启后由 WorkManager 重新调度，并重新扫描目录跳过已经完成的歌曲。
- 先写入隐藏临时文件；下载或校验失败时删除临时文件，成功后再改为正式文件名。
- 扫描下载目录及其子目录，通过 Android 媒体元数据接口展示本地歌曲。
- 在本地歌曲卡片上长按可请求永久删除对应音频源文件；删除前必须二次确认，只允许删除当前授权目录树内精确匹配的音频，不会连带删除同名 LRC。删除正在播放的歌曲时会先停止播放并释放媒体会话。
- 点击本地歌曲即可播放；底部悬浮迷你播放器提供播放/暂停和真实播放队列，完整播放页提供上一首、下一首、播放模式和进度拖动，并正确处理音频焦点及耳机断开事件。
- 播放器由 Media3 `MediaSessionService` 前台媒体服务托管。退出界面或从最近任务中划走应用时，正在播放的歌曲不会随 Activity 销毁，系统通知栏、锁屏、耳机及外部设备可继续控制播放。
- 播放状态通过 Android 标准 `MediaSession`/`MediaStyle` 发布歌曲名、歌手、专辑封面、进度和播放控制；在支持该能力的 HyperOS 3 设备上由系统自动显示为小米超级岛，不在应用内绘制仿灵动岛。
- 从原始音频标签读取并缓存专辑封面，在本地列表、迷你播放器和“正在播放”页面显示真实封面。
- “正在播放”页面读取 MP3 内嵌 SYLT 同步歌词；没有内嵌歌词时读取音频旁边的同名 LRC，随播放进度高亮并自动滚动，点击歌词可跳转；同一时间戳的原文和中译作为一组同时高亮。
- 相同文件名和大小的歌曲不会重复下载；同名但不同内容会使用带序号的新文件名。

批量下载不做音频文件内的字节级断点续传：失败的当前歌曲会从头重试，之前已经完成的歌曲不会重复下载。用户在系统设置中“强行停止”应用仍会终止媒体服务；这是 Android 的系统级行为。

## 界面设计

- 本地曲库采用浅色、扁平的歌曲列表：顶部提供“播放全部”和曲目数量，正在播放的歌曲使用低对比度底色与品牌红强调。
- 有当前歌曲时显示“继续播放”快捷行；底部播放器使用与内容分离的白色悬浮胶囊，右侧队列按钮会打开可操作的本地播放列表。
- 完整播放页使用专辑封面生成沉浸式模糊背景；没有封面时使用 Lyralume 自有的中性渐变，不依赖在线图片。
- 点击大封面或右上角歌词按钮可切换封面视图和歌词视图。歌词视图将当前原文显示为高亮大字、译文显示为次级高亮，其他歌词降低透明度；点击任意歌词仍可跳转。
- UI 只借鉴移动音乐播放器常见的信息层级和沉浸交互，不复制第三方应用的品牌、会员、关注、评论或社交数据。没有真实业务状态支撑的控件不会伪造展示。

## 构建

要求 JDK 17 或更高版本、Android SDK 34，以及可用的 Android SDK Build Tools。项目已固定 AGP 8.8.2、Gradle 8.10.2、Kotlin 2.2.0、Compose BOM 2024.09.03、Media3 1.4.1、WorkManager 2.9.1 和 OkHttp 5.1.0。Android 端通过轻量、只读的 AWS Signature V4 客户端访问 S3 兼容 API，不依赖 Java SE 的 StAX XML API。

依赖解析优先使用阿里云的 Gradle Plugin、Google Maven 和 Maven Central 镜像，并保留官方仓库兜底，便于中国网络环境和已有 Gradle 缓存稳定构建；依赖坐标与锁定版本不因此改变。

```powershell
cd android
.\gradlew.bat testDebugUnitTest
.\gradlew.bat lintDebug
.\gradlew.bat assembleDebug
```

Debug APK 位于：

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

### 正式签名构建

正式 APK 使用项目专用的长期发布密钥。密钥与密码配置位于被 Git 忽略的
`android/signing/lyralume-release.p12` 和
`android/signing/keystore.properties`。必须同时离线备份这两个文件；丢失后将无法为
同一 `applicationId` 发布可覆盖升级的新版本。

```powershell
cd android
.\gradlew.bat testDebugUnitTest lintRelease assembleRelease
```

调试签名版不能直接覆盖安装正式签名版。首次迁移需要卸载调试版，再安装正式版；之后只要
持续使用同一发布密钥即可直接升级。

本机 SDK 路径写入被忽略的 `android/local.properties`，不要提交个人路径。其他环境可自行创建：

```properties
sdk.dir=C\:\\Android\\Sdk
```

## 使用

1. 打开“设置”，选择下载目录。Android 11 及以上版本不允许直接授权存储根目录或系统 Download 根目录，可选择其下的自建子目录。
2. 填写与桌面端相同的 MinIO API、Bucket、用户名和密码，保存后测试连接。
3. 切换到“远程音乐”刷新列表；可下载单曲，也可点击“一键下载未下载”在后台依次完成剩余歌曲。首次使用后台下载时建议允许通知，以便随时查看进度或停止任务。
4. 完成的文件会自动出现在“本地音乐”。

应用允许用户配置 HTTP 端点，因此 Manifest 开启了明文网络能力。公网 MinIO 应使用有效 HTTPS 证书；界面会对 HTTP 配置持续显示警告。
